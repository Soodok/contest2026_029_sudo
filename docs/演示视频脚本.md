# 演示视频拍摄脚本（≤5 分钟）

> 大赛必交材料。要求：含**功能演示、交互操作、AI 能力展示**。
> 设备：小米手环 9（已装《资料库》v1.16.73）+ 手机（可选，用于蓝牙/AI 演示）。
> 建议：手机支架固定拍摄手环，屏幕亮度调高，环境光充足。

## 分镜表

| 时间 | 画面 | 操作 | 旁白要点 |
|---|---|---|---|
| 0:00–0:20 | 手环外观（能看出型号）→ 点亮屏幕 → 应用图标 → 首页 | 展示设备与入口 | "《资料库》——把一座离线知识馆装进手腕。" |
| 0:20–1:20 | 首页搜索：输入"健康"（只打两个字）→ 结果秒出 → 点第一条 → 词条详情（条目名/年份地区/关键词/正文）→ 返回 | 打字要拍清"只输了 1-2 个汉字" | "手表上打字贵。我们只打一两个字：本地索引直接命中，全程离线、无网秒开。" |
| 1:20–2:10 | 返回首页 → 点"诗词"入口 → 资料页（图标/简介/标签）→ 点"唐朝"标签（变蓝）→ 页内搜索"李白" → 结果 → 进详情 | 展示标签筛选 + 页内搜索 | "点进资料集可以按标签筛选；搜索结果就地在资料页里出，不用来回跳。" |
| 2:10–3:00 | 语音搜索（**AI 能力展示**）：回首页点"语音搜索"→ 对话筒说"心肺复苏" → 识别文本自动填入 → 结果列表出现。再点"AI搜索"说一个问题 → 回答卡出现（含来源条目） | 说话清楚；手机需与手环连接 | "解放双手：语音识别后本地立刻检索；AI 搜索还能给出总结回答和出处。" |
| 3:00–4:10 | **蓝牙资料传输（亮点）**：手机端发起发送资料集 → 手环自动进入传输页（进度条 0→100%，当前文件名）→ 自动跳建索引页 → 回首页 → 搜到新资料集的条目 | 全程录手环屏幕 | "资料可以随时扩充：手机蓝牙直接下发新资料集，手环自动建索引，不用重装应用。" |
| 4:10–4:40 | 收藏功能：详情页点收藏 → 回首页进"收藏" → 列表可见 → 移除 | | "收藏、历史、设置这些日常功能也都齐备。" |
| 4:40–5:00 | 设置页（版本号/清缓存/蓝牙接收入口）→ 收尾字幕："《资料库》· sudo 队 · 完全离线" | | "完全离线、零依赖，一个能真正用起来的手腕知识库。" |

## 录制要点

1. **优先拍手环实拍画面**（评委要看真机），手机画面作为补充（蓝牙发送那一段）。
2. **重点时长分配**：检索 1 分钟、资料页搜索 1 分钟、语音+AI 1 分钟、蓝牙传输 1 分钟——这四项覆盖"功能 + 交互 + AI"三个要求。
3. 如时间紧张，可裁剪收藏/设置段，**但蓝牙传输段不要删**（差异化和完整度得分点）。
4. 录制完导出 mp4/mov 即可（命名建议：`演示视频-sudo-资料库.mp4`）。
